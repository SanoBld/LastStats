Comprendre Last.fm et le scrobbling

Qu'est-ce que Last.fm ?

Last.fm est un service qui garde un historique de tout ce que vous écoutez, peu importe l'app ou la plateforme utilisée (Spotify, Apple Music, un lecteur local, etc.). LastStats se branche sur ce compte pour transformer cet historique en statistiques et en dashboard. LastStats n'est pas Last.fm : c'est une app indépendante qui vient simplement afficher vos données.

C'est quoi un « scrobble » ?

Un scrobble, c'est un titre enregistré comme écouté sur votre compte Last.fm : c'est le terme officiel pour « une écoute comptée ». Chaque fois qu'un morceau est scrobblé, il vient s'ajouter à votre historique, et c'est sur cet historique que LastStats calcule vos tops artistes, vos statistiques, vos niveaux et vos succès.

⚠️ LastStats n'enregistre aucun scrobble lui-même, l'app se contente d'afficher ceux déjà présents sur votre compte.

Quelle app utiliser pour scrobbler ?

Pour que vos écoutes remontent automatiquement sur Last.fm, il vous faut un « scrobbler ». Sur Android, l'app la plus recommandée est Pano Scrobbler : elle détecte ce que vous écoutez dans n'importe quelle app de musique (Spotify, YouTube Music, etc.) et l'envoie sur Last.fm. Beaucoup de lecteurs desktop (comme Spotify) ont aussi une connexion Last.fm intégrée, activable directement dans leurs paramètres.

Comment connecter LastStats à mon compte ?

  1. Si vous n'avez pas encore de compte Last.fm, créez-en un gratuitement sur last.fm.
  2. Installez un scrobbler (ex. Pano Scrobbler) ou activez le scrobbling depuis votre lecteur de musique habituel, pour que vos écoutes commencent à s'enregistrer.
  3. Ouvrez LastStats, entrez votre nom d'utilisateur Last.fm, puis une clé API. Vous pouvez en créer une gratuitement sur la page « Créer une clé API » du site de Last.fm.
  4. Optionnel : pour utiliser les favoris, renseignez aussi une clé secrète Last.fm dans le même écran, ou plus tard depuis Paramètres > Compte.

Questions fréquentes

LastStats scrobble-t-il ma musique ?

Non. LastStats se contente d'afficher les scrobbles déjà enregistrés sur votre compte Last.fm, elle n'en enregistre aucun elle-même. Pour scrobbler automatiquement votre musique, il vous faut une app dédiée comme Pano Scrobbler (sur Android).

C'est quoi un « scrobble » ?

Un scrobble, c'est un titre enregistré comme écouté sur votre compte Last.fm, c'est le terme officiel de Last.fm pour « une écoute comptée ». Tous vos totaux (top artistes, statistiques, etc.) sont basés dessus.

Une version iOS est-elle prévue ?

Non, pas pour le moment. Si la demande devient suffisamment forte, ce sera reconsidéré.

L'application fonctionne-t-elle sur macOS ou d'autres plateformes ?

LastStats Mobile est développée et testée sur Android. Le fonctionnement sur les autres plateformes (macOS, Windows, Linux…) n'est pas garanti, des bugs ou comportements inattendus restent possibles.

LastStats est-elle open source ?

Oui ! Le code source est en libre accès sur GitHub. C'est un projet indépendant, fait avec passion par SanoBld. Vous pouvez y contribuer, signaler un bug ou juste laisser une étoile ⭐.

Où sont stockées mes données ?

Uniquement sur votre appareil. LastStats n'a pas de serveur, vos scrobbles sont mis en cache en local pour aller plus vite, et vos identifiants Last.fm restent aussi sur votre appareil. Rien n'est envoyé ailleurs qu'à l'API officielle de Last.fm.

Comment activer les favoris ?

Allez dans Paramètres > Compte et renseignez votre clé secrète Last.fm. Une fois connectée, vous pourrez ajouter des titres en favori directement depuis l'application.

Comment fonctionnent les niveaux et les succès ?

Votre niveau de compte augmente avec votre nombre total de scrobbles, il n'y a pas de maximum. Les cartes affichent aussi une bordure (du bronze à l'iridescent) selon le nombre d'écoutes de l'artiste, du titre ou de l'album concerné. Tout est calculé automatiquement à partir de vos statistiques déjà en cache, sans requête supplémentaire.

Comment fonctionne le mode éco ?

Le mode éco espace les synchronisations automatiques pour économiser la batterie. Vous pouvez l'activer vous-même ou laisser l'application le faire selon le niveau de batterie, depuis Paramètres > Général.

Comment sauvegarder ou restaurer mes données ?

Allez dans Paramètres > Sauvegarde. Vous pouvez exporter un fichier de sauvegarde (avec ou sans votre clé Last.fm) puis le réimporter plus tard ou sur un autre appareil.

L'application fonctionne-t-elle hors ligne ?

Oui, dans une certaine mesure. Les statistiques déjà chargées restent consultables sans connexion grâce au cache local, mais une connexion reste nécessaire pour récupérer de nouveaux scrobbles.

Puis-je changer de compte Last.fm ?

Oui. Depuis Paramètres > Compte, déconnectez-vous puis reconnectez-vous avec un autre nom d'utilisateur. Le cache local est réinitialisé automatiquement pour éviter tout mélange de données.

Comment configurer les notifications ?

Depuis Paramètres > Notifications, vous pouvez activer les alertes de fin de synchronisation, choisir leur fréquence, ou les désactiver complètement si vous préférez.
