Démarrage et tutoriel

Tutoriel : de zéro à vos premières stats

Ce guide suit le chemin complet, du compte Last.fm jusqu'à l'écran de stats. Comptez quelques minutes si vous avez déjà un compte, un peu plus si vous partez de zéro.

  1. Créez un compte Last.fm (gratuit) sur last.fm/join. Retenez bien votre nom d'utilisateur : c'est lui que LastStats vous demandera.
  2. Installez un scrobbler pour que vos écoutes soient envoyées à Last.fm. Le choix dépend de votre appareil : voir la section Scrobbler sa musique.
  3. Vérifiez que ça marche : écoutez un titre, puis ouvrez votre profil sur last.fm. Il doit apparaître dans vos écoutes récentes. Tant que ce n'est pas le cas, LastStats n'aura rien à afficher.
  4. Créez une clé API sur la page de création de clé API de Last.fm : donnez un nom et une description de votre choix à l'application, puis copiez la clé affichée à la fin.
  5. Ouvrez LastStats, saisissez votre nom d'utilisateur Last.fm et la clé API, puis validez.
  6. Optionnel : les favoris. Renseignez aussi la clé secrète Last.fm, sur le même écran ou plus tard dans Paramètres > Compte.
  7. Laissez l'app charger votre historique. Le premier chargement dépend de la taille de votre historique ; ensuite le cache local rend l'affichage plus rapide.

Sources : Last.fm : inscription · Last.fm : créer une clé API · Last.fm API

Comment ça marche ?

Trois maillons, chacun indépendant des autres : 1. votre lecteur de musique (ou un scrobbler) envoie chaque écoute à Last.fm ; 2. Last.fm conserve l'historique sur votre compte ; 3. LastStats lit cet historique via l'API publique de Last.fm et le transforme en statistiques.

LastStats n'a pas de serveur : le cache de vos écoutes et vos identifiants restent sur votre appareil (détails dans les mentions légales). Conséquence pratique : si une écoute n'est pas sur Last.fm, elle n'apparaîtra jamais dans LastStats.

Créer et gérer son compte Last.fm

L'inscription se fait sur last.fm/join. Les réglages de votre compte (profil, confidentialité, applications connectées) sont regroupés dans vos paramètres Last.fm.

  • Les services reliés à votre compte (par exemple Spotify) se gèrent dans Applications.
  • Le nom d'utilisateur Last.fm est celui qu'il faut saisir dans LastStats, pas votre nom d'affichage.
  • Pour changer de compte dans LastStats : Paramètres > Compte, déconnexion, puis nouvelle connexion.

Sources : Last.fm : paramètres · Last.fm : applications

Clé API et clé secrète : à quoi ça sert ?

  • Clé API : identifie l'application auprès de Last.fm et permet de lire votre historique. Indispensable pour utiliser LastStats.
  • Clé secrète : optionnelle, nécessaire seulement pour les actions qui écrivent sur votre compte, comme les favoris.
  • Ne partagez jamais ces clés. Une sauvegarde exportée peut les contenir : la clé secrète n'y est incluse que si vous le choisissez.

Comprendre Last.fm et le scrobbling

Qu'est-ce que Last.fm ?

Last.fm est un service qui garde un historique de tout ce que vous écoutez, peu importe l'app ou la plateforme utilisée (Spotify, Apple Music, un lecteur local, etc.). LastStats se branche sur ce compte pour transformer cet historique en statistiques et en dashboard. LastStats n'est pas Last.fm : c'est une app indépendante qui vient simplement afficher vos données.

C'est quoi un « scrobble » ?

Un scrobble, c'est un titre enregistré comme écouté sur votre compte Last.fm : c'est le terme officiel pour « une écoute comptée ». Chaque fois qu'un morceau est scrobblé, il vient s'ajouter à votre historique, et c'est sur cet historique que LastStats calcule vos tops artistes, vos statistiques, vos niveaux et vos succès.

⚠️ LastStats n'enregistre aucun scrobble lui-même, l'app se contente d'afficher ceux déjà présents sur votre compte.

Quelle app utiliser pour scrobbler ?

Pour que vos écoutes remontent sur Last.fm automatiquement, il vous faut un « scrobbler ». Sur Android, l'app la plus recommandée est Pano Scrobbler : elle détecte ce que vous écoutez dans n'importe quelle app de musique (Spotify, YouTube Music, etc.) et l'envoie sur Last.fm. Beaucoup de lecteurs desktop (comme Spotify) ont aussi une connexion Last.fm intégrée, activable directement dans leurs paramètres.

Comment connecter LastStats à mon compte ?

  1. Si vous n'avez pas encore de compte Last.fm, créez-en un gratuitement sur last.fm.
  2. Installez un scrobbler (ex. Pano Scrobbler) ou activez le scrobbling depuis votre lecteur de musique habituel, pour que vos écoutes commencent à s'enregistrer.
  3. Ouvrez LastStats, entrez votre nom d'utilisateur Last.fm, puis une clé API. Vous pouvez en créer une gratuitement sur la page « Créer une clé API » du site de Last.fm.
  4. Optionnel : pour utiliser les favoris, renseignez aussi une clé secrète Last.fm dans le même écran, ou plus tard depuis Paramètres > Compte.

Scrobbler sa musique

Android

Pano Scrobbler détecte ce que vous écoutez dans vos apps de musique et l'envoie à Last.fm. Le projet est open source (code sur GitHub).

Pour qu'il détecte vos écoutes, il faut lui accorder l'accès aux notifications quand il le demande. Si les scrobbles s'arrêtent, vérifiez aussi que l'économiseur de batterie d'Android ne ferme pas l'app en arrière-plan.

Sources : Pano Scrobbler (GitHub)

iPhone et iPad

Last.fm tient une liste de scrobblers par plateforme sur sa page « Track My Music » : c'est la source à consulter pour iOS, car l'offre évolue. À noter : LastStats ne propose pas de version iOS officielle pour le moment, mais Last.fm fonctionne indépendamment.

Windows, macOS, Linux

Deux options : activer la connexion Last.fm intégrée à votre lecteur (quand il en a une), ou installer un scrobbler. Les scrobblers recommandés par Last.fm pour chaque système sont listés sur Track My Music.

Navigateur (YouTube, SoundCloud, etc.)

Pour la musique écoutée dans un onglet, l'extension open source Web Scrobbler envoie les écoutes de nombreux sites vers Last.fm.

Spotify

Spotify peut être relié directement à Last.fm depuis la page Applications : le scrobbling se fait alors côté compte, quel que soit l'appareil utilisé.

Si les écoutes ne remontent plus, la solution la plus courante est de déconnecter puis reconnecter Spotify sur cette même page. Évitez d'activer plusieurs scrobblers pour la même source, sinon vous risquez des doublons.

Sources : Last.fm : applications · Spotify Community

Utiliser LastStats

Sauvegarder et changer d'appareil

  1. Sur l'ancien appareil : Paramètres > Sauvegarde, puis exportez un fichier de sauvegarde (avec ou sans votre clé Last.fm).
  2. Transférez le fichier sur le nouvel appareil, par exemple via un cloud ou un câble.
  3. Installez LastStats, puis importez le fichier depuis Paramètres > Sauvegarde.

Un fichier exporté avec votre clé peut contenir des identifiants : gardez-le privé.

Changer de compte Last.fm

Paramètres > Compte, déconnectez-vous puis reconnectez-vous avec un autre nom d'utilisateur. Le cache local est réinitialisé automatiquement pour éviter tout mélange de données.

Batterie et notifications

  • Mode éco : espace les synchronisations automatiques ; activable à la main ou automatiquement selon le niveau de batterie (Paramètres > Général).
  • Notifications : alertes de fin de synchronisation, fréquence réglable ou désactivation complète (Paramètres > Notifications).

Dépannage

LastStats n'affiche aucune statistique

  1. Ouvrez votre profil sur last.fm : y a-t-il des écoutes ? Si non, le problème vient du scrobbler, pas de LastStats.
  2. Vérifiez le nom d'utilisateur (celui de l'URL de votre profil) et la clé API : recopiez-les sans espace avant ou après.
  3. Vérifiez votre connexion : une connexion est nécessaire pour récupérer de nouveaux scrobbles.

Des écoutes récentes manquent

  • Vérifiez d'abord qu'elles sont bien sur Last.fm : LastStats ne peut afficher que ce que Last.fm contient.
  • Sur Android, un scrobbler fermé par l'économiseur de batterie cesse d'envoyer les écoutes.
  • Pour Spotify, déconnectez puis reconnectez le lien sur la page Applications.
  • Relancez une synchronisation dans l'app une fois le scrobbler corrigé.

Toujours bloqué ?

Rejoignez le Discord ou ouvrez un ticket sur GitHub. Indiquez votre appareil, la version de LastStats et ce que vous avez déjà essayé.

Questions fréquentes

LastStats scrobble-t-il ma musique ?

Non. LastStats se contente d'afficher les scrobbles déjà enregistrés sur votre compte Last.fm, elle n'en enregistre aucun elle-même. Pour scrobbler automatiquement votre musique, il vous faut une app dédiée comme Pano Scrobbler (sur Android).

C'est quoi un « scrobble » ?

Un scrobble, c'est un titre enregistré comme écouté sur votre compte Last.fm, c'est le terme officiel de Last.fm pour « une écoute comptée ». Tous vos totaux (top artistes, statistiques, etc.) sont basés dessus.

Une version iOS est-elle prévue ?

Non, pas pour le moment. Si la demande devient suffisamment forte, ce sera reconsidéré.

L'application fonctionne-t-elle sur macOS ou d'autres plateformes ?

LastStats est développée et testée sur Android. Le fonctionnement sur les autres plateformes (macOS, Windows, Linux…) n'est pas garanti, des bugs ou comportements inattendus restent possibles.

LastStats est-elle open source ?

Oui ! Le code source est en libre accès sur GitHub. C'est un projet indépendant, fait avec passion par SanoBld. Vous pouvez y contribuer, signaler un bug ou juste laisser une étoile ⭐.

Où sont stockées mes données ?

Uniquement sur votre appareil. LastStats n'a pas de serveur, vos scrobbles sont mis en cache en local pour aller plus vite, et vos identifiants Last.fm restent aussi sur votre appareil. Rien n'est envoyé à l'éditeur ; seules des requêtes vers Last.fm et des services d'images/métadonnées (Deezer, MusicBrainz, etc.) partent de votre appareil — voir les mentions légales.

Comment activer les favoris ?

Allez dans Paramètres > Compte et renseignez votre clé secrète Last.fm. Une fois connectée, vous pourrez ajouter des titres en favori directement depuis l'application.

Comment fonctionnent les niveaux et les succès ?

Votre niveau de compte augmente avec votre nombre total de scrobbles, il n'y a pas de maximum. Les cartes affichent aussi une bordure (du bronze à l'iridescent) selon le nombre d'écoutes de l'artiste, du titre ou de l'album concerné. Tout est calculé automatiquement à partir de vos statistiques déjà en cache, sans requête supplémentaire.

Comment fonctionne le mode éco ?

Le mode éco espace les synchronisations automatiques pour économiser la batterie. Vous pouvez l'activer vous-même ou laisser l'application le faire selon le niveau de batterie, depuis Paramètres > Général.

Comment sauvegarder ou restaurer mes données ?

Allez dans Paramètres > Sauvegarde. Vous pouvez exporter un fichier de sauvegarde (avec ou sans votre clé Last.fm) puis le réimporter plus tard ou sur un autre appareil.

L'application fonctionne-t-elle hors ligne ?

Oui, dans une certaine mesure. Les statistiques déjà chargées restent consultables sans connexion grâce au cache local, mais une connexion reste nécessaire pour récupérer de nouveaux scrobbles.

Puis-je changer de compte Last.fm ?

Oui. Depuis Paramètres > Compte, déconnectez-vous puis reconnectez-vous avec un autre nom d'utilisateur. Le cache local est réinitialisé automatiquement pour éviter tout mélange de données.

Comment configurer les notifications ?

Depuis Paramètres > Notifications, vous pouvez activer les alertes de fin de synchronisation, choisir leur fréquence, ou les désactiver complètement si vous préférez.
