Propriété intellectuelle

LastStats est un projet open source. Le code source est disponible sur GitHub sous la licence indiquée dans le dépôt. Les captures d'écran, logos et textes de ce site restent la propriété de leur auteur.

Données personnelles

Ce site vitrine ne comporte ni formulaire, ni compte utilisateur, ni outil d'analyse d'audience (analytics), ni publicité, ni cookie. Il ne collecte aucune donnée personnelle et ne réalise aucun suivi des visiteurs.

Vos préférences de langue et de thème (clair/sombre/auto) sont enregistrées uniquement dans le stockage local (localStorage) de votre navigateur, restent sur votre appareil et ne sont jamais transmises à un serveur.

Les statistiques GitHub (étoiles, dernière version) et les liens de téléchargement affichés sur ce site sont récupérés en direct, depuis votre navigateur, via l'API publique de GitHub — voir la politique de confidentialité de GitHub.

L'application LastStats elle-même utilise l'API Last.fm pour afficher vos statistiques d'écoute ; son fonctionnement est détaillé dans la page d'aide de l'application, pas sur ce site vitrine.
